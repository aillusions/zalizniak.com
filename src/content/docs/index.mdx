## About Me

I'm Oleksandr. I build [Flowrensic](https://flowrensic.com/)™, forensics for durable execution. It finds out why workflows get stuck, fail, or quietly burn money.

Before that, twenty years on backend systems: cloud infrastructure and microservices on AWS, across SaaS, e-commerce, fintech, and telecom. Founding engineer and CTO of an AI native SaaS platform. Before that, lead backend architect at UserWay, where our services ran at peaks near 10,000 requests per second.

I started in Java and .NET, moved to Node and TypeScript, and now write Go. My focus is distributed systems, concurrency, and bugs that only appear in production.

Upstate, NY.

## What I've Done

- **Products from zero to production.** Architecture, backend, infrastructure, observability. Including an AI native contract platform built end to end: an agent runtime on Temporal, a document processing service, and a React frontend.
- **Backend and cloud architecture.** Microservices in Node and Java. AWS (ECS, Fargate, Lambda, RDS, Aurora, S3), Terraform, autoscaling, cost work.
- **Durable workflows in production.** A year running LLM agents on Temporal. That is where Flowrensic came from.
- **Formal methods, applied.** TLA+, Quint, and my own TypeScript model checker, run against real production workflow code.
- **Technical leadership.** Cross-functional teams of backend, frontend, and QA engineers, from idea to launch. GDPR, SOC 2, and ISO 27001 work.

## Flowrensic™ <Badge text="pre-launch" variant="caution" />

Your workflow engine shows you state. [Flowrensic](https://flowrensic.com/) shows you causes: why a run is stuck, which activity keeps retrying, what broke after the deploy.

Code intelligence for durable workflow engines. Bugs caught in the code, replay against real histories, runtime signals traced back to the line. Temporal first.

## SpecCraft <Badge text="on hold" variant="note" />

[SpecCraft](https://speccraft.io/) is a guide to formal methods for TypeScript developers. It starts from bugs you have probably seen: a database connection opened twice at startup, a search box showing results for the word you typed two keystrokes ago, a binary search that misses the last element. Then it shows how TLA+, Quint, Dafny, and Lean find them.

I started it after hitting the same wall twice, ten years apart. A part of my own system that I could not divide, refactor, or test my way out of, because the complexity was only in my head and never written down anywhere I could point at. Writing a spec is what made it visible. The site is still up, on hold while I work on Flowrensic.
