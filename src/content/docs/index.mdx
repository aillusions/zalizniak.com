## About Me

I'm Oleksandr. I build [Flowrensic](https://flowrensic.com/)™, forensics for durable execution. It finds out why workflows get stuck, fail, or quietly burn money.

Before that, twenty years on backend systems: cloud infrastructure and microservices on AWS, across SaaS, e-commerce, fintech, and telecom. Founding engineer and CTO of an AI native SaaS platform. Before that, lead backend architect at UserWay.

My passion is effortless durable execution: workflow engines, the code that runs on them, and the tooling around both.

I live in Upstate, NY.

## What I've Done

- **Product engineering.** Architecture, backend, infrastructure, and observability. Most recently an AI native contract platform: an agent runtime on Temporal, a document processing service, and a React frontend.
- **Backend and cloud architecture.** Distributed systems on AWS, built to stay up under load and to cost what they should.
- **Durable execution.** A year running LLM agents on Temporal. That is where Flowrensic came from.
- **Formal methods, applied.** TLA+, Quint, and my own TypeScript model checker, run against real production workflow code.
- **Technical leadership.** Cross-functional teams of backend, frontend, and QA engineers, from idea to launch. GDPR, SOC 2, and ISO 27001 work.

## Flowrensic™ <Badge text="pre-launch" variant="caution" />

Your workflow engine shows you state. [Flowrensic](https://flowrensic.com/) shows you causes: why a run is stuck, which activity keeps retrying, what broke after the deploy.

Code intelligence for durable workflow engines. Bugs caught in the code, replay against real histories, runtime signals traced back to the line. Temporal first.

## SpecCraft <Badge text="on hold" variant="note" />

[SpecCraft](https://speccraft.io/) is a guide to formal methods for TypeScript developers. It starts from bugs you have probably seen, then shows how TLA+, Quint, Dafny, and Lean find them.

I started it after hitting a part of my own system I could not refactor or test my way out of. Writing a spec is what made it visible. The site is still up, on hold while I work on Flowrensic.

## Signus.ai <Badge text="co-founder" variant="note" />

[Signus.ai](https://signus.ai/) is an AI native contract intelligence platform, built around Sigi, a legal agent that generates, signs, analyzes, and tracks agreements at scale. I co-founded it and built it from zero as CTO: backend, agent service, frontend, and infrastructure.

The agent runtime runs on Temporal, with durable workflows for chat, redline, risk analysis, and contract questions. That is where I learned how hard these workflows are to debug once they are live, which is the reason Flowrensic exists.
